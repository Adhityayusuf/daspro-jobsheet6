# Daspro Jobsheet 6 — Switch Case & Percabangan Lanjutan

Program latihan **percabangan lanjutan** pada Java: `switch case`
dan pemilihan nilai dengan berbagai kondisi.

## Daftar Program

| Program | Deskripsi |
|---------|-----------|
| `BilangaanTerbesar.java` | Mencari bilangan terbesar dari 3 angka |
| `BilanganTerbesar2.java` | Versi alternatif |
| `Pemilihan2Percobaan113.java` | Percobaan switch case 1 |
| `Pemilihan2Percobaan213.java` | Percobaan switch case 2 |
| `Pemilihan2Percobaan313.java` | Percobaan switch case 3 |
| `TokoBuku.java` | Studi kasus kasir toko buku |
| `TokoSepatu.java` | Studi kasus kasir toko sepatu |

## Cara Menjalankan

```bash
javac TokoBuku.java
java TokoBuku
```
